# 분석 렌즈

인터뷰 유형마다 **분석 축·대조표 축·follow-up 성격**만 바꾼다. 레이아웃과 밀도 규약은 그대로.

각 렌즈는 다음 4개를 정의한다.

- **분석 축** — 심층분석 블록이 파고들 방향 (4개)
- **대조표** — `closing.table`의 두 열. 여기가 렌즈의 정체다
- **주인공** — `tone: primary`를 누구에게 줄 것인가
- **follow-up 성격** — 마무리에 남길 것

---

## 사용자 리서치

제품을 쓰는 사람에게 무엇이 막히는지 듣는다.

```
분석 축    JTBD(진짜 하려는 일) / 멘탈모델 갭 / 경쟁 대체재 / 지불 의사
대조표     사용자가 꼽은 우선순위   vs   우리 판단
주인공     사용자
follow-up  받기로 한 자료, 재접촉 약속, 미검증 가설, design partner 전환 여부
```

핵심 질문: **요청한 기능 뒤의 결함은 무엇인가.** 사용자는 해법을 말하지 문제를 말하지 않는다.

---

## 이탈 인터뷰

떠난 사람에게 왜 떠났는지 듣는다. 진술한 이유와 실제 트리거는 대개 다르다.

```
분석 축    이탈 트리거(사건) / 잔존 가치(그래도 좋았던 것) / 대체 수단 / 복귀 조건
대조표     진술한 이탈 사유   vs   실제 트리거
주인공     이탈자
follow-up  복귀 조건 검증 실험, 같은 코호트 확인, 가격 민감도 재측정
```

핵심 질문: **결정을 내린 날 무슨 일이 있었는가.** "비싸서"는 이유가 아니라 사후 합리화인 경우가 많다.

---

## 전문가 자문

도메인 전문가에게 조언을 듣는다. 조언을 그대로 받아적으면 안 된다.

```
분석 축    주장 / 근거 강도 / 반증 가능성 / 적용 조건(우리 맥락에서 성립하는가)
대조표     조언   vs   우리 맥락에서의 적용 가능성
주인공     전문가
follow-up  검증할 가정, 추가로 물어볼 것, 조언 중 채택하지 않기로 한 것과 그 이유
```

핵심 질문: **이 조언이 성립하려면 무엇이 참이어야 하는가.** 그 전제가 우리에게도 참인지 따로 확인한다.

---

## 채용 면접

```
분석 축    주장한 경험 / 확인된 증거 / 미확인 영역 / 신호와 소음 구분
대조표     지원자 주장   vs   확인된 증거
주인공     지원자
follow-up  다음 라운드에서 확인할 것, 레퍼런스 체크 항목
```

핵심 질문: **어디까지가 관찰이고 어디부터가 인상인가.** 주석에 평가 대신 근거를 쓴다.

주의: 사람에 대한 판단이 문서로 남는다. 추측을 사실처럼 쓰지 않는다.

---

## 팀 회고 / 사후분석

```
분석 축    사건 순서 / 기여 요인 / 구조적 원인 / 재발 조건
대조표     표면 원인   vs   구조적 원인
주인공     없음 — 화자 전원 muted, 또는 발제자만 primary
follow-up  구조 변경 항목, 재발 방지 실험, 관측 지표
```

핵심 질문: **같은 조건이 다시 오면 또 일어나는가.** 개인 귀책으로 끝나면 회고가 아니다.

---

## 세일즈 디스커버리

```
분석 축    현재 해결 방식 / 비용(시간·돈·리스크) / 의사결정 구조 / 도입 장벽
대조표     고객이 말한 니즈   vs   예산·권한이 실제로 있는 곳
주인공     고객
follow-up  다음 미팅에서 확인할 것, 챔피언 후보, 계약 경로의 병목
```

핵심 질문: **이 사람에게 결정권이 있는가.** 열정과 구매력은 다른 축이다.

---

## 렌즈가 없는 유형

새로 만들되 반드시 위 형태를 따른다: **분석 축 4개 + 대조표 2축 + 주인공 + follow-up 성격.**

대조표 축을 정하는 요령 — 이 인터뷰에서 **말해진 것과 실제로 그런 것이 어긋나는 지점**이 어디인지 찾는다. 그 축이 대조표가 된다. 다른 인터뷰에 그대로 써도 되는 축이면 잘못 잡은 것이다.
