# recipes-svg.md — SVG 좌표계 관례 + 박스·화살표 도식

박스와 화살표가 필요한 순간 SVG로 넘어온다. 아래 좌표계는 관례다 — 값을 재발명하지 말고
이 그리드 위에서 배치만 설계하라. 완성 사례: `examples/swimlane-2pass.html`(정석),
`examples/agent-loop.html`(루프·와이드 박스).

## §swimlane — 가로 스윔레인 (실행 주체 여럿인 시스템의 기본형)

**좌표계 관례 (그대로 쓴다):**

```
캔버스        viewBox="0 0 1880 H" · style="max-width:1860px; width:100%"
레인          rect x=140 width=1720, 세로로 적층. 높이: 단일행 레인 100~110,
              병렬 서브행이 있는 레인은 (행수 × 96) + 40
레인 라벨      왼쪽 컬럼 x=20~140 — 중앙 x=80에 lane-h 텍스트 1~2줄 (레인 세로 중앙)
컬럼(슬롯)     피치 178: cx_i = 229 + 178·(i-1)   → c1=229 c2=407 c3=585 c4=763
              c5=941 c6=1119 c7=1297 c8=1475 c9=1653  (9컬럼이 1880폭의 한계)
박스          w=150 h=76, x = cx-75. 컬럼 간 화살표 여백 28px
박스 텍스트    제목(bt 19px)  y = box_y + 26
              부제(bs 13px)  y = box_y + 52  — 부제는 반드시 1줄, 150px 안에 들어가게 짧게
와이드 박스    컬럼 여러 개 스팬: x = cx_first - 75, width = (cx_last - cx_first) + 150
              (루프·LLM처럼 여러 컬럼을 관장하는 주체)
```

**화살표는 전부 manhattan elbow.** 박스 가장자리에서 4px 띄우고 시작, 도착 박스 4px 앞에서 끝:

```html
<path class="conn" d="M304,195 L328,195"/>                    <!-- 같은 행 옆 컬럼 -->
<path class="conn" d="M233,158 L233,220 L340,220"/>           <!-- 아래 레인 다음 컬럼: ↓→ -->
<path class="conn" d="M1424,330 L1442,330 L1442,120 L1456,120"/> <!-- 위 레인으로: →↑→ -->
<path class="conn" d="M407,472 L407,237"/>                    <!-- 저장소→위 (수직 관통: 빈 컬럼으로) -->
```

수직으로 여러 레인을 관통하는 화살표는 **빈 컬럼 자리**로 지나가게 한다. 지나갈 자리가
없으면 배치를 바꾼다 (선이 박스를 뚫으면 실패).

**긴 흐름은 블록 적층으로 접는다:** 단계 15개↑ 한 줄이면 가로가 터진다. 의미 있는 경계
(패스·페이즈·단계)에서 잘라 [블록 1 (레인 3개)] → [전폭 경계 밴드] → [블록 2 (레인 4개)]로
위아래 적층. 경계 밴드는 `rect.box.f-paper` 전폭 + 제목/부제 텍스트. 블록 이름표는
`rect + text.lbl`을 블록 좌상단(첫 블록) / 우상단(다음 블록)에.

**신호 wire:** 흐름이 아닌 정보 전달(플래그·이벤트)은 wire(2.5px)로, 블록·레인을 가로질러도
된다 — 오히려 "경계를 넘는 신호"가 보인다. 라벨은 wire 세로 구간 옆 빈 공간에
`text-anchor:end`로 건다.

## §loop — 에이전트 루프 (사이클이 있는 흐름)

루프 주체(런타임)를 와이드 박스로, 상대(LLM)를 바로 아래 레인에 같은 폭 와이드 박스로.
사이클은 왕복 화살표 2쌍으로 그린다 — x를 서로 어긋나게:

```html
<path class="conn" d="M740,233 L740,258"/>   <!-- 루프→LLM (요청): 왼쪽 x -->
<path class="conn" d="M1140,262 L1140,237"/> <!-- LLM→루프 (응답): 오른쪽 x -->
<!-- LLM→툴 레인: tool_use ↓ / tool_result ↑ 도 같은 패턴. 라벨(bs)은
     레인 경계선을 피해 경계+8px 아래 y에 anchor:start로 -->
```

## §flowchart — 판정·분기 로직

다이아몬드는 polygon 4점. 중심 (cx,cy), 반폭 hw, 반높이 55 고정:

```html
<polygon class="box f-amber" points="cx,cy-55 cx+hw,cy cx,cy+55 cx-hw,cy"/>
<text x="cx" y="cy" style="font-size:19px">조건?</text>
```

- hw는 라벨 길이에 맞춰 95~135. 판정 텍스트는 7자 이내로 압축한다.
- YES/NO 라벨(lbl 17px): 가로 화살표는 선 위 y-23, 세로 화살표는 선 오른쪽 x+16 anchor:start.
- 배치 정석: 판정 체인은 **가로로 직진**, 결과(터미널 박스)는 **아래로 드롭**.
  우선순위 파생 규칙(첫 매치가 이김)을 그릴 때 특히 — 왼쪽부터 순서가 곧 우선순위다.
- 판정은 amber, 터미널은 의미 색(성공 green · 실패/재검토 red · 중립 paper·blue).

## §sequence — 시퀀스 다이어그램

```
액터 헤더    rect w=200 h=70, y=10 — 색은 주체 의미론대로
라이프라인   line class="lane 대신" stroke 4px, 헤더 중앙 x, y=80→끝
메시지      가로 conn, 60~70px 간격으로 내려가며. 라벨(lbl)은 선 위 y-22 중앙
왕복/응답    방향만 반대로 (점선 금지 — 이 스타일에 점선은 없다)
```

## §chevron — 선형 단계 (주체 하나뿐일 때 스윔레인 대신)

```html
<!-- 첫 조각: 왼쪽 평평 -->
<polygon class="box f-blue"  points="10,10 230,10 260,70 230,130 10,130"/>
<!-- 이후 조각: 왼쪽 노치 — 앞 조각 화살촉이 파고든 모양 (x0 = 이전 화살촉 x) -->
<polygon class="box f-green" points="260,10 480,10 510,70 480,130 260,130 290,70"/>
```

피치 250, 화살촉 돌출 30. 텍스트 중심은 도형 중심보다 +15 오른쪽.

## §mini-cut — 패널용 미니 비유 컷 (dense slide 안)

viewBox 560×210 안에서 그림 하나 = 메시지 하나. 사례(strategy-slide.html):
- **비닝 다이**: 큰 rect + 내부 2px 그리드 선 → 화살표 → 작은 칩 3개(위에서부터 흰 rect를
  덮어 fuse-off 표현, 경계는 3px 검정선)
- **desire path**: 초록 field rect + 정식 경로(흰 세로 밴드) + 발자국(black circle r4.5
  대각 배열 — 점선 금지의 유일한 예외인 '의도적 도트') → 두 번째 field에서 대각 polygon
  흰 밴드로 포장
- 미니 컷 텍스트는 13px/11.5px 두 급만.

## 검증 루프에서 SVG가 단골로 걸리는 것

1. **부제(bs) 오버플로** — 150px 박스에 부제가 길다. 줄이거나 제목만 남긴다.
2. **라벨이 레인 경계선(y)에 걸침** — 경계 y ± 8px 안에 텍스트 중심을 두지 않는다.
3. **박스가 레인/캔버스 폭 초과** — 마지막 컬럼 박스 우변(cx+75)이 1856을 넘는지 셈해본다.
4. **화살표가 박스 관통** — 수직 관통 경로에 박스가 새로 생겼는지 배치 변경 때마다 재확인.
5. viewBox 높이 잔여 여백 — 마지막 요소 y + 30으로 잘라낸다.
