# Review Doc

검토 대상을 **코멘트 가능한 단일 HTML**로 변환한다. 코멘트/저장/복사 로직은 `assets/template.html`에 완성돼 있고, 내가 하는 일은 **콘텐츠를 항목 단위로 잘라 끼우는 것뿐**이다.

## 만드는 법

1. `${CLAUDE_PLUGIN_ROOT}/assets/template.html`을 읽는다.
2. placeholder 5개를 치환한다:
   - `{{DOC_TITLE}}` — 문서 제목 (2곳에 등장, 모두 치환)
   - `{{DOC_ID}}` — localStorage 네임스페이스용 안정적 slug (예: `lullu-skill-v1`). **한번 정하면 바꾸지 말 것** — 바꾸면 저장된 코멘트와 연결이 끊긴다.
   - `{{GENERATED}}` — 부제(생성 맥락/날짜 등). 비워도 됨.
   - `{{LANG}}` — UI 언어. `ko` 또는 `en`. **검토 대상 콘텐츠의 언어를 따른다** (사용자가 명시하면 그쪽 우선). 버튼·토스트·복사 결과 헤더가 전부 이 값을 따른다.
   - `{{ITEMS}}` — 항목 블록들 (아래 형식)
3. 완성본을 사용자가 지정한 경로(없으면 `/tmp/<doc-id>.html`)에 저장하고 경로를 안내한다.

## 항목(`{{ITEMS}}`) 형식

각 검토 단위는 하나의 `section.ritem`:

```html
<section class="ritem" id="고유-slug" data-title="사람이 읽는 항목 제목">
  <h2 class="ritem__title">사람이 읽는 항목 제목 <span class="tag">선택적 배지</span></h2>
  <div class="ritem__body">
    <!-- 임의 HTML: <p>, <ul>, <pre><code>, <table> 등 자유 -->
  </div>
</section>
```

- `id`는 영문 slug로 **고유**하게. 복사 결과에 `#id`로 박혀 항목 식별자가 된다.
- `data-title`은 복사 결과 헤더에 쓰인다(`## [n] 제목 (#id) — ✅ 승인`).
- 승인/거절 버튼과 코멘트 `textarea`는 JS가 자동으로 각 항목 끝에 붙인다. **직접 넣지 말 것.**
- 본문에 코드를 넣을 땐 `&lt; &gt; &amp;`로 이스케이프.

## 항목 분할 기준 (넓지도 좁지도 않게)

한 항목 = **하나의 독립적 판단이 가능한 덩어리**. 코멘트 한 개로 끝낼 수 있는 크기.

```
대상            분할 단위
─────────────── ──────────────────────────────
산문/기획 문서   소제목(H2/H3) 섹션 단위
규칙/가이드      규칙 그룹 단위 (개별 불릿 X — 너무 좁음)
코드             함수·클래스·논리 블록 단위 (한 줄 X)
스킬/프롬프트     섹션 단위 (전체 1덩어리 X — 너무 넓음)
디자인/UI        화면·컴포넌트 단위
```

너무 좁으면(불릿마다) 코멘트 피로, 너무 넓으면(통째로) 어디를 가리키는지 모호. **5~20개 항목**이 보통 적정.

## 동작 보장

- 외부 의존성 0, 라이트 테마. 파일 하나로 열림(`file://` OK).
- UI 문자열은 템플릿 상단 `I18N` 객체 한 곳에 모여 있고 `{{LANG}}`로 고른다. 로직·CSS는 언어와 무관하게 단일 경로다.
- 각 항목에 ✓승인 / ✗거절 토글 버튼(다시 누르면 해제) + 선택 코멘트칸. 버튼만 눌러도 기록 → 빠른 승인/거절.
- 승인/거절·코멘트 모두 입력 즉시 localStorage 저장(코멘트 `reviewdoc:<doc-id>:<item-id>`, 상태 `…:status`). 카드 좌측 색 바로 상태 표시(승인 초록·거절 빨강·코멘트 청록).
- "결과 전체 복사" → 승인/거절·코멘트가 있는 항목만 마크다운으로 복사. 각 항목에 `[번호] 제목 (#id) — ✅승인/❌거절/💬코멘트` 식별자+상태 포함.
- 상단 진행 카운터(승인·거절·코멘트/전체), "초기화" 버튼(확인 후 전체 삭제).
