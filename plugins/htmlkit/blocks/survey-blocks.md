# survey 블록

`formats/survey.html` 의 `{{BODY}}` 에 순서대로 채운다. 클래스만 쓰고 색은 절대 하드코딩하지 않는다.

항목이 수십 개인 문서용이다. **한 항목 = h3 하나 + 뱃지 하나 + 실측표 하나**가 기본 리듬이고, 그 리듬이 문서 끝까지 반복된다. 서술이 필요하면 `<p>`를 사이에 넣되, 항목 하나가 한 화면을 넘기면 쪼갠다.

---

## masthead — 제목 + 한 줄 출처

```html
<h1>PDF 처리 아이디어 서베이</h1>
<div class="sub">2026-01 ~ 09-03 세션·기획문서·rnd 실험에서 복원 · 중복 제거 · 상태 표기</div>
```

`.sub` 는 mono 한 줄. 무엇을 근거로 언제까지 훑었는지를 적는다. 부제목이 아니라 **범위 선언**이다.

---

## 계보 맵 — 문서 전체를 한 장으로

목차가 아니라 **관계도**다. 항목이 40개 넘어가면 독자가 먼저 이걸 보고 어디를 읽을지 정한다.

```html
<pre>2026-01 ──────── 04 ──────── 06-18 ──────── 08-19 ──── 09-03
│                             │                          │
├── A · 계보 이름 ────────────┤                          │
│   한 줄 설명                 종료                       │
│                             ├── B · 계보 이름 ─────────┤
│                             │                ↑ 여기서 멈춤
└── C · 계보 이름 (A·B 양쪽에 걸침)</pre>
```

---

## section — 계보 경계

```html
<h2><span class="n">A</span>계보 이름</h2>
<p class="lede">이 계보가 무엇을 하려던 것인지 한 줄. 기간과 종료 여부를 붙인다.</p>
```

`.n` 은 알파벳이나 숫자. mono·회색·400 weight로 물러나 있고 제목이 산다. 위쪽 검정 2px 괘선은 shell이 그린다.

---

## 항목 — 이 format 의 핵심 단위

```html
<h3><span class="id">A1</span>아이디어를 한 문장으로<span class="tag good">구현</span></h3>
<p>무엇을 하려던 것인지 두 문장 이내. 배경이 아니라 <b>내용</b>을 적는다.</p>
<pre>              전          후
문자      358,245자    38,591자
토큰      148,478      13,986      → 90.6% 감소</pre>
<div class="src">세션 748bf54e(01-05) · splitter.py:_validate_sections</div>
```

`.id` 는 `계보문자 + 번호`. 문서 안에서 항목을 가리킬 때 쓴다(`A4의 방식이 D1에서 다시 나온다`).

뱃지 5종 — 색은 look 토큰에서 온다.

```
class="tag good"   구현 · 채택 · 배포됨
class="tag bad"    폐기 · 기각 · sunset
class="tag"        계획만 · 미구현        (기본 = accent)
class="tag warn"   rnd · 실험만 · 벤치 완료
class="tag info"   진단만 · 제안
```

라벨 문구는 자유지만 **문서 안에서 일관되게** 쓴다. `구현`과 `배포됨`을 섞지 않는다.

---

## 실측표 — pre 안에 정렬

마크다운 표 대신 `pre` 를 쓴다. 숫자 자릿수를 맞춰야 훑을 수 있고, 80자 넘는 줄이 잦다.

```html
<pre>              중앙값    p90     p99      최대
유저당 파일 수      3      16     137    12,137
유저당 PDF 수       2       7      37     1,807</pre>
```

강조가 필요하면 `<b>`, 주석은 `<span class="c">`, 상태는 `.g`/`.a`/`.r`.

---

## 전환점 — 문서에 한두 번

여러 항목의 운명을 한꺼번에 바꾼 발견에만 쓴다. 남발하면 아무것도 안 튄다.

```html
<div class="pivot">
<b>전환점 · 한 줄 제목</b>
<p style="margin:8px 0 0">무엇을 확인했고 그래서 무엇이 무너졌는지.</p>
<pre style="margin-top:12px">근거가 되는 실측</pre>
</div>
```

변형: `.pivot.good`(확정·채택), `.pivot.bad`(무산·철회).

## 비교표 — 채택안 강조

```html
</table>
```

## foot — 근거 목록

```html
<footer>
근거 · plans/260830_outline_samples.html · trees/rnd/rnd/drive_index_lab/ · sessionhub 세션 20여 개
</footer>
```

문서를 재현할 수 있는 경로만 적는다. 감사 문구나 서명은 넣지 않는다.
