# relay-ko 번역 규칙

[2] 번역과 [3] 검수에서 본다. 일본어 원고를 주(主), 터키어 원고를 보조로 삼아 한국어를 만든다.

---

## 1. 프레임 유지

번역 프레임이 풀리는 것. 그게 이 스킬의 유일한 실패 방식이다. 긴 글에서는 반드시 풀린다. 그래서 풀리지 않게 처리를 잘게 나눈다.

섹션 ID 단위로 끊어서 처리한다. 한 번에 전체를 훑어 읽지 않는다.

일본어 문단 N에 한국어 문단 N을 대응시킨다. 문단 수가 바뀐 순간, 그건 이미 번역이 아니라 작문이다.

문단을 옮기기 전에 일본어 문장 수를 센다. 한국어 문장 수가 그보다 많으면 쪼갠 이유를 댈 수 있어야 한다. 적으면 내용이 날아간 것이다.

"여기는 이렇게 쓰는 게 낫겠다"는 판단이 나오면 거기서 멈춘다. 그 판단은 스펙을 고정하는 단계에서 끝냈어야 하는 것이지, 번역 도중에 꺼낼 게 아니다.

---

## 2. 의역의 허용 범위

```
허용   문장 층위. 명제 1개 → 한국어 문장 1~2개
       어순 조정, 조사 선택, 어휘 교체, 문장 분할
금지   문단 재구성, 문단 병합, 논증 순서 변경
       원문에 없는 예시·비유·부연 추가
       원문에 있는 단서·조건·수치 생략
```

---

## 3. 일본어투 처리

다음 표현이 일본어 원고에 보이면 직역하지 않는다. 표의 처리 열이 기본값이다.

```
JA 표현               직역(금지)         처리
──────────────────────────────────────────────────────────────
〜という              ~라고 하는         대개 삭제. 남기면 번역투 확정
〜において            ~에 있어서         ~에서 / ~의 경우 / 삭제
〜に対して            ~에 대해서         ~에게 / ~을 상대로 / ~과 달리
〜に関して            ~에 관해서         ~ 관련 / 삭제
〜となる              ~이 되다           ~이다
〜を行う              ~을 행하다         본동사로 (検討を行う → 검토한다)
〜のである            ~인 것이다         ~이다. 강조가 필요하면 어순으로
〜と思われる          ~라고 생각된다     ~로 보인다 / 단정
〜される (수동)       ~되어진다          능동으로 복원. 행위자는 TR에서 확인
〜ことができる        ~할 수 있다        허용하되 한 문단 1회
〜的                  ~적                한 문단 2회 이상이면 재작성
体言止め              명사 종지          서술어를 복원한다
〜ではないだろうか    ~이지 않을까       단정으로 바꾼다
〜すること            ~하는 것           명사형 남발. 동사로 되돌린다
〜に他ならない        ~에 다름 아니다    ~이다
〜と言える            ~라고 할 수 있다   ~이다
```

수동태는 기본적으로 능동으로 되돌린다. 일본어는 한국어보다 수동을 훨씬 많이 쓴다. 일본어 원고에 수동이 나오면 먼저 능동으로 복원한다. 행위자가 일본어에서 빠져 있으면 터키어 원고의 같은 자리를 본다. 터키어는 동사가 인칭을 표시하므로 행위자가 남아 있는 경우가 많다.

문장 길이는 터키어로 잰다. 일본어는 접속조사로 문장을 얼마든지 이을 수 있다. 60자를 넘는 일본어 문장이 나오면 터키어 대응 문장을 확인한다. 터키어에서 두 문장으로 갈라져 있으면 한국어도 가른다.

## 4. 한자어 승계 판정

일본어 한자어를 한국어 한자어로 자동 치환하지 않는다. 판정 기준은 하나뿐이다. 한국인이 실제 문서에서 그 단어를 쓰는가.

```
JA            직역            판정
────────────────────────────────────────────────────────────
検討する      검토하다        그대로
確認する      확인하다        그대로
考慮する      고려하다        그대로
把握する      파악하다        그대로
発生する      발생하다        그대로 / 구어 맥락이면 "생긴다"
実施する      실시하다        대개 "한다". 제도·정책 맥락에서만 "실시"
行う          행하다          금지. 목적어의 본동사로
対応する      대응하다        "처리한다" / "맞춘다" / 맥락에 따라 그대로
構築する      구축하다        "만든다". 시스템 맥락이면 그대로
実現する      실현하다        "된다" / "가능해진다"
必要となる    필요하게 되다   "필요하다"
可能性がある  가능성이 있다   "~일 수 있다"
留意する      유의하다        "주의한다"
以下の        이하의          "아래"
上記の        상기의          "위" / "앞서 말한"
当該          당해            "그" / "해당"
及び          및              허용하되 1문단 1회
中核          중핵            금지. "핵심" / "중심"
事業会社      사업회사        금지. "일반 기업"
規模の感覚    규모 감각       금지. "규모"
対比          대비            "~와 비교" / "갈라지는지"
狙い          노림수          금지. "노리는 것" / "~하겠다는 뜻"
耐用年数      내용연수        회계 맥락만. 일반 문장에서는 "수명"
```

판정이 헷갈리면 터키어 원고를 본다. 터키어에는 한자어가 없으니 같은 명제를 순수한 동사와 명사로 표현해뒀다. 그쪽을 한국어 고유어로 옮기는 게 대개 정답이다.

이 판정을 건너뛰는 게 이 스킬에서 가장 자주 나는 실패다. 문법은 맞고 문장도 매끄럽게 읽힌다. 그래서 그냥 지나가버린다.

---

## 5. 터키어 대조

터키어는 언제든 편다. 횟수를 아끼지 않는다.

특히 다음 자리에서는 반드시 본다. ① 일본어 특유의 구문이 보일 때. 수동태, 〜という, 〜において, 〜のである, 명사 종지. ② 행위자가 흐려질 때. ③ 논리 접속이 모호할 때. 「が」가 역접인지 단순 연결인지 판별이 안 되는 경우가 여기 해당한다. ④ 한자어를 그대로 옮기려 할 때.

첫 번째 예를 든다. 일본어 「この点については慎重な検討が求められると言えるでしょう」를 그대로 직역하면 "이 점에 대해서는 신중한 검토가 요구된다고 할 수 있을 것입니다"가 된다. 이건 폐기한다. 터키어는 같은 명제를 "Bu noktanın dikkatle değerlendirilmesi gerekir"라고 말해뒀다. 그 골격으로 옮기면 "이 부분은 신중하게 따져봐야 한다"가 된다.

두 번째 예. 일본어 「決定された」에는 누가 결정했는지가 없다. 터키어 "karar verdik"는 인칭 어미로 주어를 남겼다. 그래서 "우리가 정했다"로 복원할 수 있다.

```
TR                  한국어
──────────────────────────────
ancak / fakat       그러나 / 다만
çünkü               왜냐하면 → 대개 "~기 때문이다"로 뒤에 붙임
dolayısıyla         따라서
ayrıca              또한 / 게다가
buna karşılık       반면
yine de             그럼에도
```

터키어가 접속사 없이 문장을 끊었으면 한국어도 끊는다. 억지로 잇지 않는다.

## 6. 검수 — 전문 통독

한국어 완성본, 일본어 원고, 터키어 원고를 처음부터 끝까지 다 읽는다. 전부다.

grep, 키워드 카운트, 체크리스트, 일부 발췌로 대체하지 않는다. 그건 검수가 아니라 린트다.

린트가 잡는 건 문법 패턴뿐이다. 딱딱한 한자어를 그대로 승계한 어휘는 문법이 맞으니 전부 통과한다. 게다가 린트 결과를 숫자로 내면 검수가 끝난 것처럼 보인다.

읽는 방법을 지정한다. 한국어 문단을 읽고, 같은 자리의 일본어 문단과 터키어 문단을 옆에 나란히 놓는다. 그 상태로 문장마다 두 가지를 묻는다. ① 이 문장을, 이 단어를 한국인이 실제 문서에서 이렇게 쓰는가. ② 터키어는 같은 명제를 뭐라고 말했는가.

걸린 자리에서 한국어를 고치지 않는다. 해당 일본어 문장으로 돌아가 터키어 골격으로 다시 옮긴다.

```
· "~것입니다" / "~라고 할 수 있다" 가 살아남았다
· 문단 첫 문장이 전부 같은 리듬이다
· 3항 나열이 연속으로 나온다
· 원문에 없는 비유·부연이 들어갔다
· 섹션 ID 기준으로 JA와 문단 수가 어긋난다
· 한자어가 딱딱하다 — 中核 → "중핵", 事業会社 → "사업회사" 같은 승계 흔적
```

위 목록은 검사 항목이 아니라 실패했을 때 나타나는 증상이다. 그것만 확인하고 통과시키면 또 놓친다.
